# App de Análise de Vendas de Veículos

## Descrição
Este é um aplicativo web interativo feito com Streamlit que permite explorar dados de anúncios de vendas de veículos. O usuário pode visualizar o conjunto de dados completo, analisar a distribuição de preços e verificar a relação entre a quilometragem e o valor dos veículos.

## Funcionalidades
- Exibir uma tabela interativa com os dados completos de vendas
- Gerar um histograma para analisar a distribuição de preços dos veículos
- Gerar um gráfico de dispersão comparando a quilometragem (`odometer`) e o preço (`price`) dos carros
